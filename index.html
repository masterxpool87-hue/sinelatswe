သင့်ဆိုင်လုပ်ငန်းကို တစ်နေရာတည်းမှာ စီမံခန့်ခွဲပါ

နေ့စဉ်လုပ်ငန်းဆောင်တာများမှ စာရင်းပြန်လည်သုံးသပ်ခြင်းအထိ လိုအပ်သည့် အဓိကလုပ်ဆောင်ချက်များကို App တစ်ခုတည်းတွင် စုစည်းထားပါသည်။

ပင်မစာမျက်နှာ (Dashboard)

လုပ်ငန်း၏ ငွေကြေးအခြေအနေနှင့် အဓိကအချက်အလက်များကို တစ်နေရာတည်းတွင် ခြုံငုံကြည့်ရှုနိုင်ပါသည်။

အရောင်း (Sales)

Customer ရွေးချယ်ခြင်း၊ ပစ္စည်းထည့်ခြင်း၊ Discount၊ ပို့ဆောင်ခနှင့် ငွေပေးချေမှုများကို စီမံနိုင်ပါသည်။

ပစ္စည်းစာရင်း (Inventory)

ကုန်ပစ္စည်းဓာတ်ပုံ၊ Code၊ လက်ကျန်အရေအတွက်၊ အရင်းဈေးနှင့် ရောင်းဈေးတို့ကို ထည့်သွင်းစီမံနိုင်ပါသည်။

အဝယ်စာရင်း (Purchases)

Supplier၊ ဝယ်ယူသည့်ရက်စွဲ၊ ပစ္စည်းနှင့် ဝယ်ဈေးများကို မှတ်တမ်းတင်ပြီး ပစ္စည်းရောက်ရှိမှုကို Stock ထဲသို့ ထည့်နိုင်ပါသည်။

ကုန်ကျစရိတ် (Expenses)

လုပ်ငန်းအတွက် အသုံးစရိတ်များကို မှတ်တမ်းတင်ပြီး အရောင်းနှင့် ကုန်ကျစရိတ်ကို ပြန်လည်သုံးသပ်နိုင်ပါသည်။

Charts & Reports

ရောင်းအားနှင့် ကုန်ကျစရိတ်များကို Bar၊ Pie၊ Line Chart များဖြင့် အမြင်ပိုင်းဆိုင်ရာ သုံးသပ်နိုင်ပါသည်။

Customer & History

ဖောက်သည်စာရင်းနှင့် အရောင်းမှတ်တမ်းများကို Customer အမည်၊ ရက်စွဲအလိုက် ရှာဖွေစစ်ဆေးနိုင်ပါသည်။

Data Backup / Restore

လုပ်ငန်းဒေတာများကို ဖုန်း၏ Downloads Folder ထဲသို့ Backup ထုတ်နိုင်ပြီး ပြန်လည်ရယူနိုင်ပါသည်။

Voucher & Bluetooth Printer

Voucher ကို Bluetooth Printer ဖြင့် Print ထုတ်နိုင်ပြီး Image အဖြစ် Gallery ထဲသို့လည်း သိမ်းဆည်းနိုင်ပါသည်။

USER GUIDE

ဆိုင်လက်စွဲ App အသုံးပြုနည်း

အောက်ပါအပိုင်းတစ်ခုချင်းစီကို နှိပ်ပြီး အသေးစိတ်အသုံးပြုနည်းကို ဖတ်ရှုနိုင်ပါသည်။ Video သင်ခန်းစာကိုလည်း အောက်တွင် ကြည့်ရှုနိုင်ပါသည်။

App ကို စတင်အသုံးပြုရန် သင်၏လုပ်ငန်းအချက်အလက်နှင့် ကုန်ပစ္စည်းများကို ဦးစွာ ထည့်သွင်းပါ။

  • App ၏ မည်သည့် Screen တွင်မဆို ညာဘက်အပေါ်ထောင့်ရှိ Settings Icon ကို နှိပ်ပါ။
  • “လုပ်ငန်းအချက်အလက်” အောက်တွင် ဆိုင်အမည်၊ ဆိုင်လိပ်စာ၊ ဆက်သွယ်ရန် ဖုန်းနံပါတ် တို့ကို ဖြည့်စွက်ပါ။
  • သိမ်းဆည်းမည် ကို နှိပ်ပါ။ ဤအချက်အလက်များသည် ထုတ်လုပ်မည့် Voucher တွင် အလိုအလျောက် ပါဝင်မည်ဖြစ်သည်။
  • “အဝယ်စာရင်း” Screen မှ (+) ခလုတ်ကို နှိပ်ပါ။
  • Supplier အမည်၊ ရက်စွဲ၊ ဝယ်ယူသည့်ပစ္စည်းများနှင့် ဝယ်ဈေးတို့ကို ထည့်သွင်းပြီး သိမ်းဆည်းပါ။
  • ပစ္စည်းများ ဆိုင်သို့ အမှန်တကယ်ရောက်ရှိလာသည့်အခါ သက်ဆိုင်ရာ အဝယ်မှတ်တမ်းရှိ “ပစ္စည်းမရောက်ရှိသေးပါ” ခလုတ်ကို နှိပ်ပါ။ ထိုပစ္စည်းများသည် Inventory ထဲသို့ အလိုအလျောက် ရောက်ရှိသွားမည်ဖြစ်သည်။
  • အောက်ခြေ Navigation Bar မှ ပစ္စည်းစာရင်း (Inventory) ကို နှိပ်ပါ။
  • ညာဘက်အောက်ထောင့်ရှိ အပေါင်း (+) ခလုတ်ကို နှိပ်ပြီး “ပစ္စည်းအသစ် ထည့်သွင်းပါ” ကို ဖွင့်ပါ။
  • လိုအပ်ပါက ပစ္စည်းဓာတ်ပုံ ရွေးချယ်ပါ။ ထို့နောက် ပစ္စည်းအမည် (ဥပမာ Coca-Cola)၊ Product Code (ဥပမာ COKE001)၊ လက်ကျန်အရေအတွက် (ဥပမာ 50)၊ အရင်းဈေး (ဥပမာ 700) နှင့် ရောင်းဈေး (ဥပမာ 1000) တို့ကို ဖြည့်ပါ။
  • အားလုံးပြည့်စုံပါက သိမ်းမည် ကို နှိပ်ပါ။
  • “အရောင်း” Screen သို့သွားပြီး Customer အချက်အလက် မှ ရှိပြီးသား Customer ကိုရွေးပါ သို့မဟုတ် Customer အသစ်ထည့်ပါ။
  • Scanner Icon မှ OCR (စာသား) သို့မဟုတ် Barcode Scan ဖတ်၍ ပစ္စည်းထည့်နိုင်သည်။ “+” ခလုတ်မှလည်း ပစ္စည်းရွေးထည့်နိုင်သည်။
  • Cart ထဲရှိ (+) / (-) ဖြင့် အရေအတွက် ပြင်ဆင်ပါ။ အရေအတွက်သည် လက်ကားအရေအတွက်သို့ ရောက်ပါက ဈေးနှုန်းသည် လက်ကားဈေးသို့ အလိုအလျောက် ပြောင်းလဲသွားမည်ဖြစ်သည်။
  • လိုအပ်ပါက Discount၊ ပို့ဆောင်ခ၊ ငွေပေးချေမှုအမျိုးအစားနှင့် ပို့ဆောင်ပြီး/မပြီး Status ကို ရွေးပါ။
  • ရောင်းမည် ကို နှိပ်ပါ။ Voucher ပေါ်လာပါက Bluetooth Printer ဖြင့် Print ထုတ်နိုင်သလို Save as Image ဖြင့် Gallery ထဲ သိမ်းနိုင်ပါသည်။
  • Dashboard တွင် အပေါ်ဆုံးကတ် ၄ ကတ်မှ အဓိကငွေကြေးဆိုင်ရာ အခြေအနေများကို ကြည့်ရှုနိုင်ပါသည်။ Charts များတွင် ရောင်းအားနှင့် ကုန်ကျစရိတ်ကို Bar၊ Pie၊ Line Chart များဖြင့် သုံးသပ်နိုင်ပါသည်။
  • “အရောင်း” Screen မှ မှတ်တမ်းကြည့်ရန် ကို နှိပ်ပါ။ အရောင်းမှတ်တမ်းများကို ရက်စွဲအလိုက် အုပ်စုဖွဲ့ပြသပါမည်။
  • မှန်ဘီလူး Icon ဖြင့် Customer အမည်၊ ပြက္ခဒိန် Icon ဖြင့် ရက်စွဲအလိုက် Filter လုပ်နိုင်ပါသည်။
  • မှတ်တမ်းကို ဖွင့်ပြီး Mark as Paid၊ Mark as Delivered စသည်ဖြင့် Status ပြောင်းနိုင်သည်။ ခဲတံ Icon ဖြင့် ပြင်ဆင်နိုင်ပြီး အမှိုက်ပုံး Icon ဖြင့် Cancel လုပ်နိုင်ပါသည်။ Cancel လုပ်ပါက ပစ္စည်းလက်ကျန်များ မူလအတိုင်း ပြန်ဖြစ်သွားမည်ဖြစ်သည်။
  • License Information တွင် Trial / Activated အခြေအနေကို ကြည့်ရှုပြီး Activate လုပ်နိုင်ပါသည်။
  • လုံခြုံရေး မှ App ကို PIN Lock ဖြင့် ကာကွယ်ခြင်း၊ PIN ပြောင်းလဲခြင်း ပြုလုပ်နိုင်ပါသည်။
  • ဖောက်သည်များစာရင်း မှ Customer များနှင့် ၎င်းတို့၏ အရောင်းမှတ်တမ်းများကို ကြည့်ရှုနိုင်ပါသည်။
  • Data Backup / Restore ဖြင့် Downloads Folder ထဲသို့ Backup ထုတ်ခြင်း၊ ပြန်လည်ရယူခြင်း ပြုလုပ်နိုင်ပါသည်။
  • Excel Export မှ အရောင်းစာရင်းနှင့် ပစ္စည်းစာရင်းများကို CSV File အဖြစ် Export ထုတ်နိုင်ပါသည်။
  • Printer Settings တွင် Bluetooth Printer အမျိုးအစား 58mm / 80mm အလိုက် စာတစ်ကြောင်းရှိ စာလုံးအရေအတွက်ကို ချိန်ညှိနိုင်ပါသည်။
